<h1>Metronome / Drum Machine</h1>

Created a pretty simple React app with a metronome and a drum machine

[View Project](https://jmoten212.github.io/metronome-drum-machine/) &emsp; | &emsp; [View Code](https://github.com/jmoten212/metronome-drum-machine)

<h3>Key Features</h3>
<ul>
  <li>A built-in metronome with a start/stop control and an adjustable BPM slider</li>
  <li>A 3-track drum sequencer for bass, snare and hi-hat instruments</li>
  <li>A 16-step pattern grid for each instrument with switch buttons that can be toggled on and off</li>
  <li>Loop playback with a moving active-step highlight and simple, changeable tempo presets</li>
  <li>Browser audio playback using instrument audio samples</li>
  <li>A direct link to the project's GitHub repository with tooltip UI</li>
</ul>

<h3>What I Learned</h3>
<ul>
  <li>How to best manage interactive playback state in React using declarative and imperative patterns</li>
  <li>How to build and control time-based behavior for audio loops, including tempo changes and step sequencing</li>
  <li>How to integrate and trigger browser audio samples reliably, including mobile-focused audio context handling</li>
  <li>How to improve usability of music tools through clear visual feedback and responsive controls</li>
</ul>
